GForms is Gelhaus Solutions' fork of [Formbricks](https://github.com/formbricks/formbricks). Its source code is
licensed under the [AGPLv3](https://github.com/Gelhaus-Solutions/formbricks/blob/main/LICENSE); the SDK and survey
packages named in that file keep their MIT license.

There is no Enterprise Edition, no license key and no paid plan. The code Formbricks ships under its Enterprise
license is not part of GForms, and GForms rebuilds those features as open source. A feature is either part of
GForms for every organization, or not available yet.

## What the AGPLv3 allows

You can use GForms for free, for personal and commercial purposes. You can also create and distribute modified
versions, as long as you document the changes you make, with their date, and publish your complete code under the
AGPLv3 as well. The [license text](https://github.com/Gelhaus-Solutions/formbricks/blob/main/LICENSE) is what
binds.

## Feature availability

Everything Formbricks' Community Edition offers is part of GForms: link, website and app surveys, all question
types, logic, recall, multi-language surveys, file uploads, the API and SDKs, webhooks, integrations and the Helm
chart. The features Formbricks sold under its Enterprise license stand as follows.
