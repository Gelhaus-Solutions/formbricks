Two-factor authentication (2FA) asks for a second form of verification in addition to the password, so a stolen password alone does not open the account.

Two-factor authentication cannot be turned on or off in the profile settings. An account that already has it keeps it, and is asked for the second factor every time it signs in.

## Logging in with Two-factor authentication

The login process has an additional step:

1. Enter your email and password as usual
2. When prompted, enter either:
   - A 6-digit code from your authenticator app, or
   - One of your backup codes (use format: xxxxx-xxxxx or just the 10-character code). Choose **Use a backup code** below the code boxes to enter one.

Each backup code can only be used once.

<Warning>
Store your backup codes in a secure location. If you lose access to both your authenticator device and backup codes, you will need administrator assistance to regain access to your account.
</Warning>
